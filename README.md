# SGME - Sistema de Gerenciamento de Mensalidades Escolares

Sistema desenvolvido para o gerenciamento de alunos, responsáveis financeiros, turmas e mensalidades de uma escola particular. A aplicação permite realizar cadastros, pesquisas, atualizações e consultas de dados, além da geração de relatórios para auxiliar no controle e na organização das informações escolares.  O projeto foi desenvolvido como parte da disciplina de Programação Orientada a Objetos II, no Instituto Federal de Educação, Ciência e Tecnologia do Rio Grande do Sul (IFRS) – Campus Osório.
